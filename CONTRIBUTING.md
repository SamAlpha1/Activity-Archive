# Contributing

Thank you for considering a contribution.

## Before You Start

- Open or review an issue for substantial changes so the scope can be agreed before implementation.
- Keep changes focused and avoid unrelated refactors.
- Never include credentials, personal data, generated secrets, or production configuration.

## Pull Requests

- Describe the problem and the proposed solution.
- Link related issues.
- Include or update tests for behavior changes.
- Update documentation when commands, configuration, or behavior changes.
- Keep the pull request small enough to review.

## Validation

Run the test, lint, and build commands documented in this repository's README and project configuration. Include the commands run and their results in the pull request description. Do not claim checks passed unless they were actually run.

## Review

All changes are subject to maintainer review. Security-sensitive changes may require additional review before merging.
